# Contacts Flutter

A minimal Android contacts app styled to match the approved mockup.

- Lists contacts stored on the phone and their phone numbers.
- Search by contact name or phone number.
- Tap a contact to see all saved phone numbers.
- No favorites, no recents, no call history, and no extra tabs.
- Requests read-only contacts permission.

The GitHub Actions workflow builds a release APK and uploads it as an artifact.
